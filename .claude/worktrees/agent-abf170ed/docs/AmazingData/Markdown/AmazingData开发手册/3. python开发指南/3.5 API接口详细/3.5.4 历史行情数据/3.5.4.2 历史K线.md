# 3.5.4.2 历史K线

## 函数接口

```python
query_kline()
```

**功能描述**：K线数据的实时订阅回调函数，支持全部周期的K线数据查询

## 输入参数

| 参数 | 数据类型 | 必选 | 解释 |
|------|----------|------|------|
| code_list | list:[str] | 是 | 可传入列表，支持北交所、上交所、深交所的可转债、股票、指数、ETF等品种，上交所、深交所的ETF期权；支持期货（中金所/上期所/大商所/郑商所/上海国际能源交易中心所） |
| begin_date | int | 是 | 日期，填写8位的整型格式的日期，比如20240101 |
| end_date | int | 是 | 日期，填写8位的整型格式的日期，比如20240201 |
| period | Period | 是 | 数据周期Period（见附录） |
| begin_time | int | 否 | 时分的时间戳，填写3位或4位的整型格式的日期，时占一位或两位，分占两位，例如9点整为900, 17点25分为1725 |
| end_time | int | 否 | 时分的时间戳，填写3位或4位的整型格式的日期，时占一位或两位，分占两位，例如9点整为900, 17点25分为1725 |

## 输出参数

| 参数 | 数据类型 | 解释 |
|------|----------|------|
| kline_dict | dict | 字典的key：代码<br>字典的value：dataframe，column为K线数据Kline（见附录），index为日期（datetime） |

## 示例代码

```python
# 第一步 登录api
import AmazingData as ad
```

## 边界情况返回值说明

本节记录了 `query_kline()` 接口在各种边界情况下的返回值行为。注意：**API 不会抛出异常**，所有情况都正常返回字典。

### 返回值汇总

| 情况 | 输入示例 | 返回值 | 说明 |
|------|----------|--------|------|
| 不存在的代码 | `code_list=['999999.SH']` | `{'999999.SH': None}` | 字典包含代码键，值为 `None` |
| 开始日期晚于结束日期 | `begin_date=20240630, end_date=20240601` | `{}` | 返回空字典 |
| 未来日期 | `begin_date=20360101` (晚于当前时间) | `{}` | 返回空字典 |
| 标的上市前数据 | 查询上市前的日期范围 | `{'code': None}` | 字典包含代码键，值为 `None` |
| 已退市股票 | 已退市代码 | `{'code': None}` | 字典包含代码键，值为 `None` |

### 混合代码查询

当 `code_list` 中同时包含有效和无效代码时：
- **有效代码**：返回正常 DataFrame（包含 K 线数据）
- **无效代码**：返回 `None`
- 各代码之间互不影响

示例：
```python
code_list = ['688698.SH', '688216.SH', '999999.SH']  # 前两个有效，最后一个无效
kline_dict = market_data.query_kline(code_list, begin_date=20240601, end_date=20240630)

# 返回值：
# {
#     '688698.SH': DataFrame(19, 8),  # 正常数据
#     '688216.SH': DataFrame(19, 8),  # 正常数据
#     '999999.SH': None                # 无效代码
# }
```

### 处理建议

```python
kline_dict = market_data.query_kline(code_list, begin_date, end_date, period)

# 1. 检查返回字典是否为空（参数错误）
if not kline_dict:
    logger.warning("查询参数可能错误，返回空字典")
    return

# 2. 逐一检查每个代码的返回值
results = {}
for code in code_list:
    if code in kline_dict and kline_dict[code] is not None:
        results[code] = kline_dict[code]
    else:
        logger.warning(f"代码 {code} 无数据（可能不存在、未上市或已退市）")

# 3. 处理有效数据
for code, df in results.items():
    # 处理 DataFrame
    pass
```

### 4.3.2 K线算法说明

#### （1）集合竞价的处理

对于分钟K线，开盘集合竞价数据的成交量包含在当日第一根K线，收盘集合竞价数据的成交量包含在当日最后一根K线。

#### （2）前推算法

- 9:30的1分钟K线，计算的是9:30:00.000~9:30:59.999期间的K线。
- 9:35的5分钟K线，计算的是9:35:00.000~9:39:59.999期间的K线。

## 不完整上市周期处理

| Option | Description | Selected |
|--------|-------------|----------|
| 策略 A: 上市日截断，保留不完整周期 | 从上市日期到请求结束日期，保留不完整的上市年/月 | |
| 策略 B: 只取完整周期，舍弃不完整 | 只取从上市后第一个完整周期开始，舍弃不完整的上市年/月 | ✓ |
| 策略 C: 智能混合 | 如果不完整部分的交易日占比超过阈值（如 50%），则保留；否则舍弃整个周期 | |

**User's choice:** 策略 B: 只取完整周期，舍弃不完整
**Notes:** 例如一支股票上市于 20140601，请求 2013-2016 年线时，取 2015-2016 完整年，舍弃 2014 不完整年。

## 完整周期判定

### 第一个完整周期开始日期

| Option | Description | Selected |
|--------|-------------|----------|
| 下一周期首日开始 | 20140601 上市 → 第一个完整年从 20150101 开始 | |
| 下一周期首个交易日开始 | 20140601 上市 → 第一个完整年的第一个交易日可能不是 20150101（如元旦非交易日） | ✓ |

**User's choice:** 下一周期首个交易日开始

### 周期粒度统一处理

| Option | Description | Selected |
|--------|-------------|----------|
| 统一处理，所有长周期都按此策略 | 上市日期落在月中 → 舍弃当月，从下月第一个交易日开始。上市日期落在周中 → 舍弃当周，从下周一开始 | ✓ |
| 分情况：日线/分钟线保留不完整，长周期才舍弃 | 日线和分钟线不做"只取完整周期"处理，按上市日期截断。周/月/季/年线才做完整周期处理 | |

**User's choice:** 统一处理，所有长周期都按此策略，舍弃首尾不完整周期。长周期包括周月季年线。

### 边界判断

| Option | Description | Selected |
|--------|-------------|----------|
| 按自然年判断，不看首个交易日 | 20140102 上市 → 2014 年第一天不是交易日，视为完整年 | |
| 按实际交易日判断，首个交易日即视为完整 | 20140102 上市 → 1月1日非交易日，1月2日是第一个交易日，视为完整年 | ✓ |

**User's choice:** 按实际交易日判断，首个交易日即视为完整

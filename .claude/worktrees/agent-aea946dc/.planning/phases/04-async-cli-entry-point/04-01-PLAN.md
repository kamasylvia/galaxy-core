# Plan 04-01: Convert CLI to Async Entry

## Goal

将 CLI 入口从同步执行切换到 async/await，使用 `asyncio.run()` 驱动命令处理，同时保持完全的向后兼容性（参数、输出、退出码）。

## Context

### Phase 3 已完成的基础设施

- `AsyncDatabaseManager` (async_connection.py): 提供 async engine 和 session
- `AsyncKlineService` (async_kline.py): 提供 async 查询和保存
- `execute_kline_query_async()` (sync_orchestrator.py): async 编排入口，SDK 用线程池

### 当前 CLI 状态

- `main()` (commands.py): 同步入口，直接调用 `handle_kline_command()`
- `handle_kline_command()` (command.py): 同步命令处理，使用:
  - `db_manager.initialize()` - sync database init
  - `kline_completeness_checker.check()` - sync completeness checker
  - `sync_kline_data()` - sync data synchronization

### 接口定义

```python
# From sync_orchestrator.py
async def execute_kline_query_async(
    symbol_list: list[str],
    interval: str,
    start_date: str | None,

    async_db_manager: AsyncDatabaseManager | None = None,

    """Async K-line query using ThreadPoolExecutor for SDK + async DB."""

    def __init__(self, db_manager: AsyncDatabaseManager) -> None:  # DI pattern

```

### Task 1: Create async command handler

**File**: `src/galaxy_db_sync/application/kline/command.py`

**Action**: EDIT

创建 `handle_kline_command_async()` 函数，将现有同步逻辑迁移到 async：

1. 替换 `db_manager.initialize()` 为 `async_db_manager.initialize()`（initialize 本身是 sync，只需切换使用的 manager）
2. 对于 completeness checker（仍为 sync），使用 `asyncio.to_thread()` 包装
3. 对于 `_get_listing_dates()`（sync SDK 调用），使用 `asyncio.to_thread()` 包装
4. 保持参数解析、日期推导、校验逻辑不变
5. 使用 async `sync_kline_data_async()` 替代 sync 版本（或包装 sync 版本）
6. 保持退出码语义：成功返回 0，失败返回 1
7. 保持日志输出格式不变

关键实现要点：
- `async_db_manager` 是全局 singleton，直接 import 使用
- completeness checker 仍用 sync `kline_completeness_checker`，通过 `asyncio.to_thread` 包装
- `_get_listing_dates()` 调用 sync SDK，通过 `asyncio.to_thread` 包装
- 创建 `sync_kline_data_async()` 包装现有 `sync_kline_data()`，或创建新的 async 版本

```python
async def handle_kline_command_async(args: argparse.Namespace) -> int:
    """Async version of handle_kline_command.
    
    Per ASYNC-05: Uses asyncio.run() at CLI entry.
    Per COMPAT-01: Same arguments, output, exit codes.
    """
    try:
        # ... validation logic unchanged ...
        
        # Use async_db_manager instead of sync db_manager
        from galaxy_db_sync.database.core.async_connection import async_db_manager

        # Wrap sync completeness checker
        completeness_result = await asyncio.to_thread(
            kline_completeness_checker.check,
            symbol=symbol,
            interval=interval,
            start_date=start,
            end_date=end,
        )
        
        # Wrap sync SDK calls
        listing_dates = await asyncio.to_thread(_get_listing_dates, valid_symbols)
        
        # Use async sync function
        sync_result = await sync_kline_data_async(...)
        
        return 0  # or 1 on error
    except Exception as e:
        logger.error(f"Command failed: {e}")
        return 1
```

### Task 2: Update CLI entry point to use asyncio.run()

**File**: `src/galaxy_db_sync/application/cli/commands.py`

**Action**: EDIT

修改 `main()` 函数，使用 `asyncio.run()` 驱动 async 命令处理：

1. 创建 `async_main()` async 函数
2. `main()` 包装 `asyncio.run(async_main())`
3. 保持 argparse 解析逻辑不变
4. 保持命令分发逻辑（kline → handle_kline_command_async, calendar → handle_calendar_command）
5. calendar 命令若需 async 也做类似处理，或保持 sync 用 asyncio.run 包装

```python
import asyncio

async def async_main() -> int:
    """Async CLI main entry."""
    parser = argparse.ArgumentParser(...)
    subparsers = parser.add_subparsers(...)
    
    create_kline_parser(subparsers)
    create_calendar_parser(subparsers)
    
    args = parser.parse_args()
    
    if args.command is None:
        parser.print_help()
        return 1
    
    if args.command == "kline":
        return await handle_kline_command_async(args)
    elif args.command == "calendar":
        # Calendar can remain sync or wrap with asyncio.to_thread
        return await asyncio.to_thread(handle_calendar_command, args)
    else:
        parser.print_help()
        return 1

def main() -> int:
    """CLI entry point - wraps async_main with asyncio.run()."""
    return asyncio.run(async_main())
```
